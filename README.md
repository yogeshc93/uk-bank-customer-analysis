# UK Bank Customer Analysis Dashboard

## Project Overview
An interactive dashboard developed using Microsoft Power BI to explore UK bank customer data and present key business insights.

## Objectives
- Analyse customer demographics.
- Explore customer distribution by region and job classification.
- Examine account balances and relevant key performance indicators.
- Present findings through interactive data visualisations.

## Tools Used
- Microsoft Power BI
- Power Query and DAX (if used)

## Key Metrics
- Total customers
- Total account balance
- Average account balance
